# Rubric Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Claude Code plugin that carries a project's own standards into every turn and mechanically blocks completion claims that no check stands behind.

**Architecture:** All decision logic is pure Python in the `rubric/` package, taking primitives and returning verdicts, so every rule is unit-testable without Claude Code, a network, or a filesystem. The `hooks/` and `scripts/` entry points are thin shells that read stdin, call one pure function, and write stdout. Behaviour is driven by a per-project `.claude/rubric.json` merged over a dialect preset; a project with no config gets the three questions and nothing else.

**Tech Stack:** Python 3 standard library only. `unittest` for tests. JSON for config. No third-party packages at any point.

**Spec:** `docs/superpowers/specs/2026-09-03-rubric-design.md`

## Global Constraints

Every task's requirements implicitly include this section.

- **Standard library only.** No pip, no venv, no `requirements.txt`. The hooks run under whatever `python3` a device happens to have. A dependency is a device where the kit silently stops working.
- **Every hook fails open.** Any unexpected condition exits 0 with no output. A gate that breaks a session is removed within a day and takes its protection with it.
- **Tests are stdlib `unittest`**, run with `python3 -m unittest discover -s tests -t . -v`. Never pytest.
- **Pure logic in `rubric/`, I/O in `hooks/` and `scripts/`.** No module under `rubric/` reads stdin, writes stdout, or calls `sys.exit`.
- **Observed hook contract**, recorded live on 2026-09-03 from a running session, not recalled:
  - Stop payload keys: `background_tasks`, `cwd`, `effort`, `hook_event_name`, `last_assistant_message`, `permission_mode`, `prompt_id`, `scratchpad_dir`, `session_crons`, `session_id`, `stop_hook_active`, `transcript_path`. **`cwd` is how a device-wide hook finds the project.**
  - Stop block output: `{"decision": "block", "reason": "...", "systemMessage": "..."}` printed to stdout, exit 0.
  - UserPromptSubmit output: `{"hookSpecificOutput": {"hookEventName": "UserPromptSubmit", "additionalContext": "..."}}`.
- **`rule_source` is required on every invariant.** A check that cannot cite the prose rule it enforces is policing something nobody agreed to.
- **`check_invariants.py` exits 0 always.** It reports; it never blocks a commit.
- **No em dashes, en dashes or spaced hyphens** in any string the kit prints to a user.
- **Commit after every task.** Message style: imperative mood, no attribution lines.

```python
"""Load and merge Rubric configuration.

Resolution order, later wins:

  1. DEFAULTS
  2. presets/<dialect>.json
  3. ~/.claude/rubric.json        (per device: mainly `who` and `cannot_check`)
  4. <project>/.claude/rubric.json

Objects deep-merge. Arrays replace wholesale, unless the overlay key
carries a trailing "+", in which case it appends to the inherited value.
That form exists because the common edit is "the preset is right, plus one
more command", and forcing a full retype of the preset's list is how a
rule silently disappears during an unrelated edit.

Nothing here raises. A configuration file that cannot be read is treated
as absent, because the alternative is a hook that crashes a session over a
stray comma.
"""

import json
import os

PLUGIN_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))

DEFAULTS = {
    "dialect": None,
    "who": None,
    "cannot_check": [],
    "work_files": [],
    "evidence": {"commands": [], "tools": [], "never_started": []},
    "claims": [],
    "disclaimers": [],
    "gate": {"enabled": False, "requires_work_change": True},
    "cost_table": [],
    "situations": [],
    "invariants": [],
}


def read_json(path):
    """The parsed object at `path`, or None. Never raises."""
    try:
        with open(path, encoding="utf-8", errors="replace") as handle:
            loaded = json.load(handle)
    except (OSError, ValueError):
        return None
    return loaded if isinstance(loaded, dict) else None


def deep_merge(base, overlay):
    """`overlay` applied over `base`. Objects merge, arrays replace.

    A key ending in "+" appends to the inherited array instead of
    replacing it, and the "+" is stripped from the resulting key.
    """
    out = dict(base)
    for key, value in (overlay or {}).items():
        if key.endswith("+"):
            name = key[:-1]
            inherited = out.get(name)
            out[name] = list(inherited or []) + list(value or [])
            continue
        if isinstance(value, dict) and isinstance(out.get(key), dict):
            out[key] = deep_merge(out[key], value)
        else:
            out[key] = value
    return out


def read_preset(dialect, plugin_root=None):
    """The named dialect preset, or an empty dict if there is no such file."""
    if not dialect or not isinstance(dialect, str):
        return {}
    if not dialect.replace("-", "").replace("_", "").isalnum():
        # A dialect name is a filename. Refuse anything that could traverse.
        return {}
    root = plugin_root or PLUGIN_ROOT
    return read_json(os.path.join(root, "presets", dialect + ".json")) or {}


def load(project_dir, home_dir=None, plugin_root=None):
    """`(config, project_configured)` for a project directory.

    `project_configured` is False when the project has no rubric.json. The
    gate keys on that bool rather than on the config's contents: a
    device-level file naming only `who` is not enough knowledge to judge
    what evidence means in a repository the kit has never been told about.
    """
    home_dir = home_dir if home_dir is not None else os.path.expanduser("~")

    project_cfg = read_json(os.path.join(project_dir or "", ".claude", "rubric.json"))
    user_cfg = read_json(os.path.join(home_dir, ".claude", "rubric.json"))

    merged = dict(DEFAULTS)
    merged["evidence"] = dict(DEFAULTS["evidence"])
    merged["gate"] = dict(DEFAULTS["gate"])

    dialect = (project_cfg or {}).get("dialect") or (user_cfg or {}).get("dialect")
    if dialect:
        merged = deep_merge(merged, read_preset(dialect, plugin_root))
    if user_cfg:
        merged = deep_merge(merged, user_cfg)
    if project_cfg:
        merged = deep_merge(merged, project_cfg)

    configured = project_cfg is not None
    explicit = ((project_cfg or {}).get("gate") or {}).get("enabled")
    merged["gate"]["enabled"] = configured if explicit is None else bool(explicit)

    return merged, configured
```

```python
"""Tests for the shipped dialect presets.

These assert shape and a few load-bearing behaviours, not every regex. The
point is that a preset cannot introduce a key the config does not know
about, and that the claim patterns catch what they are meant to catch
while leaving ordinary prose alone.
"""

import json
import os
import re
import tempfile
import unittest

from rubric import config

PRESETS = os.path.join(config.PLUGIN_ROOT, "presets")


def load_preset(name):
    with open(os.path.join(PRESETS, name + ".json"), encoding="utf-8") as handle:
        return json.load(handle)


def matches(patterns, text):
    return any(re.search(p, text, re.IGNORECASE) for p in patterns)


class PresetShapeTests(unittest.TestCase):
    def test_both_presets_exist_and_parse(self):
        for name in ("code", "research"):
            self.assertIsInstance(load_preset(name), dict)

    def test_presets_introduce_no_unknown_top_level_keys(self):
        known = set(config.DEFAULTS)
        for name in ("code", "research"):
            for key in load_preset(name):
                self.assertIn(key.rstrip("+"), known, "%s in %s" % (key, name))


class CodePresetTests(unittest.TestCase):
    def setUp(self):
        self.preset = load_preset("code")

    def test_claims_catch_a_completion_statement(self):
        for said in ("Fixed the parser.", "That now works.", "Tests are passing.",
                     "Verified against the store."):
            self.assertTrue(matches(self.preset["claims"], said), said)

    def test_bare_working_is_not_a_claim(self):
        for innocent in ("the working directory", "our working agreement",
                         "I am working on it"):
            self.assertFalse(matches(self.preset["claims"], innocent), innocent)

    def test_the_sanctioned_disclaimer_is_recognised(self):
        self.assertTrue(matches(self.preset["disclaimers"], "I have not checked this."))

    def test_gate_keys_on_work_changing(self):
        self.assertTrue(self.preset["gate"]["requires_work_change"])


class ResearchPresetTests(unittest.TestCase):
    def setUp(self):
        self.preset = load_preset("research")

    def test_claims_catch_an_assertion_about_a_source(self):
        for said in ("The paper says the effect vanishes.",
                     "According to the 2024 report, adoption doubled.",
                     "62% of respondents disagreed."):
            self.assertTrue(matches(self.preset["claims"], said), said)

    def test_ordinary_prose_is_not_a_claim(self):
        for innocent in ("Let me read the paper.", "I will check the data.",
                         "What does the report cover?"):
            self.assertFalse(matches(self.preset["claims"], innocent), innocent)

    def test_gate_does_not_require_an_edit(self):
        self.assertFalse(self.preset["gate"]["requires_work_change"])

    def test_reading_tools_count_as_evidence(self):
        self.assertIn("Read", self.preset["evidence"]["tools"])
        self.assertIn("WebFetch", self.preset["evidence"]["tools"])


class DialectResolutionTests(unittest.TestCase):
    def test_naming_a_dialect_inherits_its_claims(self):
        project = tempfile.mkdtemp()
        home = tempfile.mkdtemp()
        os.makedirs(os.path.join(project, ".claude"))
        with open(os.path.join(project, ".claude", "rubric.json"), "w") as handle:
            json.dump({"dialect": "code"}, handle)
        loaded, configured = config.load(project, home)
        self.assertTrue(configured)
        self.assertTrue(matches(loaded["claims"], "Fixed it."))

    def test_a_bogus_dialect_name_cannot_traverse_the_filesystem(self):
        self.assertEqual(config.read_preset("../../etc/passwd"), {})


if __name__ == "__main__":
    unittest.main()
```

```python
"""Build the text injected on every prompt.

The core block is the only string in the kit that is hardcoded rather than
configured, because it is the only thing that is genuinely universal. It is
kept deliberately short: a hook that costs a paragraph a turn becomes
wallpaper, which is exactly how the prose it replaces stopped working.

The cost table is NOT injected here. It belongs to the gate, which quotes
the one relevant row at the moment a check was skipped.
"""

import re

CORE_TEMPLATE = (
    "Before any factual claim this turn:\n"
    "  1. Checked, or recalled? If recalled and checkable in under two minutes, check it.\n"
    "  2. What did I observe, versus what am I inferring?\n"
    "  3. If I am wrong here, could {who} tell?{cannot} If no, slow down.\n"
    'Anything unchecked ships with the words "I have not checked this".'
)


def core_block(config):
    who = (config or {}).get("who") or "the user"
    domains = [d for d in ((config or {}).get("cannot_check") or []) if d]
    cannot = " They cannot check %s." % ", ".join(domains) if domains else ""
    return CORE_TEMPLATE.format(who=who, cannot=cannot)


def situation_blocks(config, prompt):
    """The `say` of every configured situation whose `when` matches `prompt`."""
    if not isinstance(prompt, str):
        prompt = "" if prompt is None else str(prompt)
    out = []
    for block in ((config or {}).get("situations") or []):
        say = (block or {}).get("say")
        if not say:
            continue
        for pattern in (block.get("when") or []):
            try:
                if re.search(pattern, prompt, re.IGNORECASE):
                    out.append(say)
                    break
            except (re.error, TypeError):
                continue
    return out


def build(config, prompt):
    return "\n\n".join([core_block(config)] + situation_blocks(config, prompt))
```

```python
#!/usr/bin/env python3
"""UserPromptSubmit hook: put the verification questions in front of every turn.

A rule in a file read at session start is buried under a hundred thousand
tokens by the time the mistake happens, so the questions arrive on every
prompt instead.

Never blocks, never errors out loud. Any unexpected condition still emits
the core block, because that block depends on nothing and silence here
would be the one turn without it.
"""

import json
import os
import sys

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from rubric import config as rubric_config  # noqa: E402
from rubric import context as rubric_context  # noqa: E402


def project_dir(payload):
    """Where this turn is happening.

    `cwd` is observed in the Stop payload; it has NOT been observed in the
    UserPromptSubmit one, so two fallbacks follow it. All three failing is
    survivable: an unconfigured project still gets the core block.
    """
    for candidate in (payload.get("cwd"), os.environ.get("CLAUDE_PROJECT_DIR")):
        if candidate and os.path.isdir(candidate):
            return candidate
    return os.getcwd()


def main():
    try:
        raw = sys.stdin.read()
        payload = json.loads(raw) if raw.strip() else {}
        if not isinstance(payload, dict):
            payload = {}
    except ValueError:
        payload = {}

    prompt = payload.get("prompt") or ""
    try:
        loaded, _ = rubric_config.load(project_dir(payload))
    except Exception:  # noqa: BLE001
        loaded = dict(rubric_config.DEFAULTS)

    text = rubric_context.build(loaded, prompt)
    sys.stdout.write(json.dumps({
        "hookSpecificOutput": {
            "hookEventName": "UserPromptSubmit",
            "additionalContext": text,
        }
    }))
    return 0


if __name__ == "__main__":
    try:
        sys.exit(main())
    except Exception:  # noqa: BLE001 - never break a session over this
        sys.exit(0)
```

```python
"""Read one turn out of a Claude Code transcript.

This is the only module that knows the JSONL record shape. Everything
downstream takes primitives, so a change to the host's transcript format
is a change to exactly one file.
"""

import json

# Injected context, slash-command echoes and hook output all arrive as user
# records. None of them is the human speaking, so none of them starts a turn.
NON_PROMPT_PREFIXES = (
    "<system-reminder", "<command-", "<local-command", "<bash-", "<user-prompt",
)


def blocks(record):
    """The content blocks of a record, normalised to a list of dicts."""
    message = (record or {}).get("message") or {}
    content = message.get("content")
    if isinstance(content, str):
        return [{"type": "text", "text": content}]
    if isinstance(content, list):
        return [b for b in content if isinstance(b, dict)]
    return []


def is_human_prompt(record):
    """True for a record that is the person typing, not a tool result."""
    if (record or {}).get("type") != "user" or record.get("isMeta"):
        return False
    for block in blocks(record):
        if block.get("type") != "text":
            continue
        body = (block.get("text") or "").strip()
        if body and not body.startswith(NON_PROMPT_PREFIXES):
            return True
    return False


def current_turn(records):
    """Records since the last human prompt.

    A subagent's lines land in the same transcript with `isSidechain` set.
    Its build is not this session's evidence and its prose is not this
    session's claim, so they are dropped before anything else looks.
    """
    own = [r for r in (records or []) if not (r or {}).get("isSidechain")]
    start = 0
    for index, record in enumerate(own):
        if is_human_prompt(record):
            start = index + 1
    return own[start:]


def assistant_text(turn):
    """Everything the user was actually told this turn.

    Thinking blocks are excluded on purpose: a claim the user never reads
    cannot mislead them, and gating on private reasoning would fire the
    hook on deliberating about whether something is fixed.
    """
    out = []
    for record in turn or []:
        if (record or {}).get("type") != "assistant":
            continue
        for block in blocks(record):
            if block.get("type") == "text":
                out.append(block.get("text") or "")
    return "\n".join(out)


def tool_uses(turn):
    """`(name, input, tool_use_id)` for every tool call this turn."""
    for record in turn or []:
        for block in blocks(record):
            if block.get("type") == "tool_use":
                yield (block.get("name") or "",
                       block.get("input") or {},
                       block.get("id") or "")


def _result_text(content):
    if isinstance(content, str):
        return content
    if isinstance(content, list):
        parts = []
        for item in content:
            if isinstance(item, dict) and item.get("type") == "text":
                parts.append(item.get("text") or "")
            elif isinstance(item, str):
                parts.append(item)
        return "\n".join(parts)
    return ""


def tool_results(turn):
    """`tool_use_id` -> result text, for results that name their call.

    An unattributed result is skipped rather than guessed at: pairing it to
    the wrong call would let one command's failure disqualify another's
    success, which is a worse error than missing a failure.
    """
    out = {}
    for record in turn or []:
        for block in blocks(record):
            if block.get("type") != "tool_result":
                continue
            key = block.get("tool_use_id")
            if not key:
                continue
            out[key] = out.get(key, "") + _result_text(block.get("content"))
    return out


def read(path):
    """Every parseable record in a transcript file. Never raises."""
    records = []
    try:
        with open(path, encoding="utf-8", errors="replace") as handle:
            for line in handle:
                line = line.strip()
                if not line:
                    continue
                try:
                    records.append(json.loads(line))
                except ValueError:
                    continue
    except OSError:
        return []
    return records
```

```python
"""Glob matching for path patterns.

Written by hand rather than reached for: `fnmatch` is not path-aware, so
its `*` happily crosses a directory separator, and `pathlib.PurePath.match`
does not treat a leading `**/` as optional. Both would silently widen or
narrow what counts as "the work", which is a rule nobody would notice
breaking.
"""

import re

_CACHE = {}


def _translate(pattern):
    out = ["(?:.*/)?"] if not pattern.startswith("**") else [""]
    index = 0
    length = len(pattern)
    while index < length:
        char = pattern[index]
        if pattern.startswith("**/", index):
            out.append("(?:.*/)?")
            index += 3
        elif pattern.startswith("**", index):
            out.append(".*")
            index += 2
        elif char == "*":
            out.append("[^/]*")
            index += 1
        elif char == "?":
            out.append("[^/]")
            index += 1
        else:
            out.append(re.escape(char))
            index += 1
    return re.compile("^" + "".join(out) + "$")


def _compiled(pattern):
    if pattern not in _CACHE:
        try:
            _CACHE[pattern] = _translate(pattern)
        except re.error:
            _CACHE[pattern] = None
    return _CACHE[pattern]


def matches(path, pattern):
    """True when `path` matches `pattern`.

    The leading `(?:.*/)?` means a relative pattern also matches an
    absolute path by its suffix, which is what makes `src/**/*.ts` work
    against the absolute file_path an edit tool reports.
    """
    if not path or not pattern:
        return False
    compiled = _compiled(pattern)
    if compiled is None:
        return False
    return bool(compiled.match(str(path).replace("\\", "/")))


def matches_any(path, patterns):
    return any(matches(path, p) for p in (patterns or []))
```

Create `rubric/gate.py`:

```python
"""Decide whether a turn may end.

Blocks when all of these hold, and only then:

  1. the gate is enabled (which means the project has a rubric.json)
  2. some assistant TEXT this turn makes a completion claim
  3. that text carries no disclaimer
  4. if the dialect requires it, a work file actually changed
  5. nothing that counts as evidence ran, or something did and its own
     output says it never started

The conjunction is deliberately tight. Discussion, refactors reported
honestly, and answering a question all pass untouched.

Nothing here does I/O. `evaluate` takes records and returns a verdict; the
hook shell is what reads stdin and prints.
"""

import re

from rubric import globs, transcript

# A shell command that WRITES, as opposed to one that merely mentions a
# path. `grep -n foo src/a.py` mentions; `cat > src/a.py` writes. Auto mode
# edits through Bash, so missing this would quietly retire the gate.
WRITE_HINTS = [
    r">\s*\S+",
    r"\bsed\s+-i\b",
    r"\btee\b",
    r"\bpatch\b",
    r"\bdd\b",
    r"\bmv\s",
    r"\bcp\s",
]
WRITE_HINT_RE = re.compile("|".join(WRITE_HINTS))
PATH_TOKEN_RE = re.compile(r"[\w./\-]+")

EDIT_TOOLS = ("Edit", "Write", "MultiEdit", "NotebookEdit")


class Verdict(object):
    """A decision to block, and the sentence explaining it."""

    def __init__(self, reason, claims):
        self.reason = reason
        self.claims = claims


class Signals(object):
    """What this turn actually contained."""

    def __init__(self, said, claims, work_changed, has_evidence):
        self.said = said
        self.claims = claims
        self.work_changed = work_changed
        self.has_evidence = has_evidence


def _search_any(patterns, text):
    for pattern in patterns or []:
        try:
            if re.search(pattern, text or "", re.IGNORECASE):
                return True
        except (re.error, TypeError):
            continue
    return False


def _found(patterns, text):
    out = []
    for pattern in patterns or []:
        try:
            out.extend(m.group(0) for m in re.finditer(pattern, text or "", re.IGNORECASE))
        except (re.error, TypeError):
            continue
    return sorted(set(out))


def work_changed(config, turn):
    """True when a path matching `work_files` was written this turn."""
    patterns = config.get("work_files") or []
    if not patterns:
        return False
    for name, tool_input, _ in transcript.tool_uses(turn):
        if name in EDIT_TOOLS:
            path = tool_input.get("file_path") or tool_input.get("notebook_path") or ""
            if globs.matches_any(path, patterns):
                return True
        elif name == "Bash":
            command = tool_input.get("command") or ""
            if not WRITE_HINT_RE.search(command):
                continue
            for token in PATH_TOKEN_RE.findall(command):
                if globs.matches_any(token, patterns):
                    return True
    return False


def has_evidence(config, turn):
    """True when something ran that actually exercised the project.

    A call whose own output matches `never_started` does not count. That
    rule exists because a build tool can print an error, do nothing, and
    still exit clean, so nothing downstream can tell it apart from a real
    run unless the output is read.
    """
    evidence = config.get("evidence") or {}
    commands = evidence.get("commands") or []
    tools = evidence.get("tools") or []
    never_started = evidence.get("never_started") or []
    results = transcript.tool_results(turn)

    for name, tool_input, use_id in transcript.tool_uses(turn):
        counted = False
        if name == "Bash":
            counted = _search_any(commands, tool_input.get("command") or "")
        else:
            counted = any(name == t or name.startswith(t) for t in tools)
        if not counted:
            continue
        if _search_any(never_started, results.get(use_id, "")):
            continue
        return True
    return False


def signals(config, turn):
    said = transcript.assistant_text(turn)
    return Signals(
        said=said,
        claims=_found(config.get("claims"), said),
        work_changed=work_changed(config, turn),
        has_evidence=has_evidence(config, turn),
    )


def _checks_available(config):
    rows = config.get("cost_table") or []
    parts = []
    for row in rows[:3]:
        check = (row or {}).get("check")
        if not check:
            continue
        cost = (row or {}).get("cost")
        parts.append("%s (%s)" % (check, cost) if cost else check)
    return parts


def _reason(config, found_claims):
    quoted = " / ".join('"%s"' % c for c in found_claims[:3])
    checks = _checks_available(config)
    if checks:
        suffix = ("Run one of these first: %s. " % "; ".join(checks))
    else:
        suffix = ("No check is configured for this project, so either run "
                  "whatever would actually settle it, or say so. ")
    return (
        "This turn told the user %s, but nothing ran that would show it. "
        "%s"
        'Otherwise write "I have not checked this" in the reply, in the '
        "sentence making the claim, and stop." % (quoted, suffix)
    )


def decide(config, computed):
    """A Verdict to block, or None to allow. Pure."""
    if not (config.get("gate") or {}).get("enabled"):
        return None
    if not computed.claims:
        return None
    if _search_any(config.get("disclaimers"), computed.said):
        return None
    if (config.get("gate") or {}).get("requires_work_change", True) and not computed.work_changed:
        return None
    if computed.has_evidence:
        return None
    return Verdict(_reason(config, computed.claims), computed.claims)


def evaluate(config, records, stop_hook_active=False):
    if stop_hook_active:
        return None
    turn = transcript.current_turn(records)
    return decide(config, signals(config, turn))
```

```python
#!/usr/bin/env python3
"""Stop hook: refuse to end a turn that claims work is done with nothing behind it.

Blocking a Stop makes the model continue, which produces another Stop. Two
independent things prevent a loop, because relying on one of them means
trusting a payload field that may not always arrive:

  * `stop_hook_active` in the stdin payload, when the host sends it;
  * a per-session marker file recording that this session was already
    blocked. One block per session is the whole intent anyway. The point
    is to interrupt the reflex once, not to argue.

Every unexpected condition exits 0 and allows the stop. A gate that breaks
a session is worse than no gate; it gets removed within a day and takes its
protection with it.
"""

import json
import os
import sys
import tempfile

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from rubric import config as rubric_config  # noqa: E402
from rubric import gate as rubric_gate  # noqa: E402
from rubric import transcript as rubric_transcript  # noqa: E402


def state_dir(payload):
    """Somewhere writable for the per-session marker.

    `scratchpad_dir` was observed in the live Stop payload. The plugin's
    own directory is deliberately not used: it lives in the plugins cache
    and is replaced wholesale on update.
    """
    base = payload.get("scratchpad_dir") or tempfile.gettempdir()
    path = os.path.join(base, "rubric-gate")
    try:
        os.makedirs(path, exist_ok=True)
    except OSError:
        return None
    return path


def already_blocked(directory, session_id):
    if not directory or not session_id:
        return False
    return os.path.exists(os.path.join(directory, "blocked-%s" % session_id))


def mark_blocked(directory, session_id):
    if not directory or not session_id:
        return
    try:
        open(os.path.join(directory, "blocked-%s" % session_id), "a").close()
    except OSError:
        pass


def main():
    try:
        payload = json.loads(sys.stdin.read() or "{}")
    except ValueError:
        return 0
    if not isinstance(payload, dict):
        return 0

    transcript_path = payload.get("transcript_path") or ""
    if not transcript_path or not os.path.exists(transcript_path):
        return 0

    directory = state_dir(payload)
    session_id = payload.get("session_id") or ""
    if already_blocked(directory, session_id):
        return 0

    loaded, configured = rubric_config.load(payload.get("cwd") or os.getcwd())
    if not configured:
        return 0

    verdict = rubric_gate.evaluate(
        loaded,
        rubric_transcript.read(transcript_path),
        stop_hook_active=bool(payload.get("stop_hook_active")),
    )
    if verdict is None:
        return 0

    mark_blocked(directory, session_id)
    print(json.dumps({
        "decision": "block",
        "reason": verdict.reason,
        "systemMessage": "Rubric: a completion claim with no check behind it.",
    }))
    return 0


if __name__ == "__main__":
    try:
        sys.exit(main())
    except Exception:  # noqa: BLE001 - never break the session over this
        sys.exit(0)
```

```python
import os
import shutil
import tempfile
import unittest

from rubric import invariants


class Tree(object):
    """A throwaway directory with files in it."""

    def __init__(self, files):
        self.root = tempfile.mkdtemp()
        for name, body in files.items():
            path = os.path.join(self.root, name)
            os.makedirs(os.path.dirname(path), exist_ok=True)
            with open(path, "w", encoding="utf-8") as handle:
                handle.write(body)

    def cleanup(self):
        shutil.rmtree(self.root, ignore_errors=True)


def rule(**overrides):
    base = {"name": "no-console", "files": "src/**/*.ts",
            "forbid": r"console\.log", "message": "use logger.ts",
            "rule_source": "CLAUDE.md > Conventions"}
    base.update(overrides)
    return base
```

```python
"""Check the conventions a grep can settle.

This exists because of a specific finding: in the audit that motivated the
whole kit, every convention violation in the tree broke a rule the project
had already written down in prose, several of them in files whose own
comments quoted the rule. Prose did not hold.

`rule_source` is mandatory for the same reason in reverse. A check that
cannot cite the rule it enforces is policing something nobody agreed to,
and the first person to hit it will be right to delete it.

Output is a triage list, not a verdict. Some flagged lines will be correct
on reading.

A future version may glob `.claude/rubric.d/*.py` for checks a regex cannot
express, such as one that has to parse a file rather than scan it. That seam
is named here and deliberately not wired: it stays closed until a project
actually has such a check, because opening it later is a change to this
module and opening it now is a contract other projects would depend on.
"""

import os
import re

from rubric import globs

SKIP_DIRS = {".git", "node_modules", "__pycache__", ".venv", "venv",
             ".build", "build", "dist", ".worktrees", "DerivedData"}


class Finding(object):
    def __init__(self, rule, path, line, text, message, rule_source):
        self.rule = rule
        self.path = path
        self.line = line
        self.text = text
        self.message = message
        self.rule_source = rule_source

    def __eq__(self, other):
        return isinstance(other, Finding) and vars(self) == vars(other)

    def __repr__(self):
        return "Finding(%r, %r, %r)" % (self.rule, self.path, self.line)


def validate(rules):
    """Human-readable problems with the rules themselves."""
    problems = []
    for index, raw in enumerate(rules or []):
        rule = raw or {}
        name = rule.get("name") or "rule %d" % (index + 1)
        if not rule.get("rule_source"):
            problems.append(
                "%s has no rule_source. Name the written rule it enforces, or "
                "delete it." % name)
        if not rule.get("files"):
            problems.append("%s has no files glob." % name)
        has_forbid = bool(rule.get("forbid"))
        has_require = bool(rule.get("require"))
        if has_forbid and has_require:
            problems.append("%s sets both forbid and require. Pick one." % name)
        elif not has_forbid and not has_require:
            problems.append("%s sets neither forbid nor require." % name)
        for key in ("forbid", "require", "allow"):
            pattern = rule.get(key)
            if not pattern:
                continue
            try:
                re.compile(pattern)
            except re.error as error:
                problems.append("%s has an invalid regex in %s: %s" % (name, key, error))
    return problems


def _files_under(root):
    for base, dirs, names in os.walk(root):
        dirs[:] = [d for d in dirs if d not in SKIP_DIRS and not d.startswith(".")]
        for name in names:
            full = os.path.join(base, name)
            yield full, os.path.relpath(full, root).replace(os.sep, "/")


def _lines(path):
    try:
        with open(path, encoding="utf-8", errors="replace") as handle:
            return handle.read().splitlines()
    except OSError:
        return []


def run(root, rules):
    """Every finding under `root`. Rules with problems are skipped."""
    usable = [r for r in (rules or []) if not validate([r])]
    if not usable:
        return []

    findings = []
    for full, relative in _files_under(root):
        for rule in usable:
            if not globs.matches(relative, rule.get("files")):
                continue
            findings.extend(_check(full, relative, rule))
    findings.sort(key=lambda f: (f.path, f.line or 0, f.rule))
    return findings


def _check(full, relative, rule):
    name = rule.get("name") or "unnamed"
    message = rule.get("message") or ""
    source = rule.get("rule_source") or ""
    comments = tuple(rule.get("skip_line_comments") or ())
    lines = _lines(full)

    if rule.get("require"):
        pattern = re.compile(rule["require"], re.MULTILINE)
        if not any(pattern.search(line) for line in lines):
            return [Finding(name, relative, None, "", message, source)]
        return []

    forbid = re.compile(rule["forbid"])
    allow = re.compile(rule["allow"]) if rule.get("allow") else None
    out = []
    for number, line in enumerate(lines, 1):
        if comments and line.strip().startswith(comments):
            continue
        if not forbid.search(line):
            continue
        if allow and allow.search(line):
            continue
        out.append(Finding(name, relative, number, line.strip()[:100], message, source))
    return out


def report(findings, problems):
    """The triage list, as text."""
    out = []
    if problems:
        out.append("Problems with the rules themselves:")
        out.extend("  %s" % p for p in problems)
        out.append("")
    if not findings:
        out.append("No findings.")
        return "\n".join(out)

    out.append("%d finding%s. These are for triage, not a verdict: read each "
               "line before changing it." % (len(findings), "" if len(findings) == 1 else "s"))
    out.append("")
    for finding in findings:
        where = "%s:%d" % (finding.path, finding.line) if finding.line else finding.path
        out.append("  %s  [%s]" % (where, finding.rule))
        if finding.text:
            out.append("      %s" % finding.text)
        out.append("      %s  (%s)" % (finding.message, finding.rule_source))
    return "\n".join(out)
```

```python
#!/usr/bin/env python3
"""Run a project's configured invariants.

    python3 scripts/check_invariants.py [project_dir]

Exit 0 always. This reports, it never blocks. A check that breaks a commit
gets deleted in annoyance and takes its protection with it.
"""

import os
import sys

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from rubric import config as rubric_config  # noqa: E402
from rubric import invariants  # noqa: E402


def main(argv):
    root = argv[1] if len(argv) > 1 else os.getcwd()
    loaded, configured = rubric_config.load(root)
    if not configured:
        print("No .claude/rubric.json in %s, so no invariants are configured. "
              "Run /rubric:setup to add some." % root)
        return 0

    rules = loaded.get("invariants") or []
    if not rules:
        print("No invariants configured for this project.")
        return 0

    problems = invariants.validate(rules)
    findings = invariants.run(root, rules)
    print(invariants.report(findings, problems))
    return 0


if __name__ == "__main__":
    try:
        sys.exit(main(sys.argv))
    except Exception as error:  # noqa: BLE001
        print("check_invariants could not complete: %s" % error)
        sys.exit(0)
```

```markdown
# Setting up Rubric for a project

Write exactly one new file, `.claude/rubric.json`. Nothing else in the
repository is modified. The plugin brings its own hook wiring, so there is
no `settings.json` to edit.

## The rule that governs this whole skill

Read before you ask. Most repositories already answer most of these
questions, and an interview that asks what the repository could have told
you wastes the one thing the person has that you do not: their judgement
about what they cannot check.

## Step 1: Detect

Gather all of this before saying anything:

| Look at | Infer |
|---|---|
| `package.json` `scripts.test` / `scripts.build` | evidence commands |
| `pyproject.toml`, `pytest.ini`, `tox.ini` | `pytest` |
| `Cargo.toml` | `cargo test`, `cargo build` |
| `go.mod` | `go test ./...` |
| `Makefile` targets named `test` or `build` | `make test` |
| existing `CLAUDE.md` or `AGENTS.md` | candidate invariants, and the `rule_source` for each |
| `git log --stat -20` | which paths are actually the work |
| none of the above, and mostly prose files | the `research` dialect |

## Step 2: Propose

Show the drafted config and say where each part came from. Say plainly
which parts are guesses.

## Step 3: Ask only what the repository cannot tell you

One question at a time.

1. **`cannot_check`** is the important one, and nothing in the repository
   knows it. Ask: "Which parts of this could you not check yourself if I
   got them wrong?" Their answer goes in verbatim. This is what makes the
   third verification question answerable rather than rhetorical.
2. **`who`**, unless `~/.claude/rubric.json` already sets it.
3. Confirm the detected commands. Do not ask whether they work. Run one
   and show the output.

## Step 4: The cost table

Ask what each kind of claim actually costs to check here, and write a row per
kind: `{ "claim": ..., "check": ..., "cost": ... }`. Time the commands rather
than estimating them.

This is not decoration. The gate quotes these rows when it blocks, so a project
with no cost table gets a block message that names no way forward. It also
exists so that "verifying would take too long" cannot be said without looking
at a number somebody measured.

## Step 5: Invariants, if the repository has written rules

For each convention stated in the project's own CLAUDE.md that a grep
could settle, propose a rule. Every rule needs `rule_source` naming where
that convention is written. If a proposed check cannot cite a written
rule, do not add it. Propose no more than five to begin with; a checker
that fires forty times on its first run gets deleted.

## Step 6: Write

Show the file as a diff first. Create `.claude/` if the repository has
none. If `.claude/rubric.json` already exists, merge into it and never
replace it.

## Step 7: Prove it

the real output. The project's first experience of the kit is a result,
not a claim that it is installed.

Then say plainly what is now in force and what is not: the gate blocks a
completion claim only when a work file changed and nothing ran, and it
blocks once per session.
```

```markdown
# Rubric

Carries a project's own standards into every turn and holds work to them.

Three mechanisms, because prose alone does not hold. The project this grew
out of recorded its own "an exit code is not proof" rule being broken about
an hour after it was written down.

| Mechanism | When it runs | What it does |
|---|---|---|
| `rubric_context.py` | every prompt | asks three verification questions, plus any situation blocks the prompt matches |
| `evidence_gate.py` | end of a turn | blocks once when work changed, a completion claim was made, and nothing ran |
| `check_invariants.py` | on demand | greps the conventions a grep can settle, and reports rather than blocks |

## Install, once per device

    claude plugin marketplace add msishuvo/claude-rubric
    claude plugin install rubric@claude-rubric

## Set up, once per project

    /rubric:setup

## What happens in a project with no config

The three questions, and nothing else. The gate stays off and the invariant
checker reports that none are configured. A gate that guesses what evidence
means in a repository it has never been told about is a gate that gets
switched off, and then it protects nothing.

## Configuration

`.claude/rubric.json`. A dialect names a preset; every other key overrides
it. An array key ending in `+` appends to the inherited value instead of
replacing it.

    {
      "dialect": "code",
      "who": "msishuvo",
      "cannot_check": ["Rust internals"],
      "work_files": ["src/**/*.rs"],
      "evidence": { "commands+": ["cargo clippy"] }
    }

Device-wide defaults, mainly `who` and `cannot_check`, go in
`~/.claude/rubric.json`. A device-level file alone does not enable the
gate; that takes a project file.

Full field reference: `docs/superpowers/specs/2026-09-03-rubric-design.md`.

## The escape hatch

The gate is not asking for a build every time. Writing "I have not checked
this" in the sentence that makes the claim passes it, because the point is
that the person reading knows which sentences are load bearing.

## Running the tests

    python3 -m unittest discover -s tests -t . -v

Standard library only. No pip, no venv.

## Known limits

- The `research` dialect is the less proven half. Retune `claims` and
  `gate.requires_work_change` against real sessions.
- Hooks exist only inside Claude Code. Nothing here helps in a plain API
  session or another editor.
- The Stop hook sees only the end of a turn, so it catches the reflex and
  not the reasoning. The written standards are still what binds.
```
